FocusForge — AI Integration Strategy

How to make the app genuinely intelligent: which AI to use, where, and at what cost.

Architecture in one sentence: Run on-device logic/ML for real-time pattern detection (zero cost, offline), use Claude Haiku via Anthropic API for personalized coaching narratives, and Claude Sonnet for the interactive AI coach — so the app feels intelligent everywhere, at a cost of ~$0.03 per active user per month.
Layer 1 — On-device intelligence (always-on, zero cost, offline)
Custom logic + lightweight ML — runs entirely on the device No API · No cost · No internet needed
⚡

Doom Loop Detection

Sliding-window open-count algorithm. If opens > 5 in 15 min with avg session < 45s → trigger mindful pause. Pure JS logic, no model needed. Instant, private.

Custom JS logic
🔮

Vulnerability Score (risk prediction)

After 14 days of data, a logistic regression trains locally using ONNX Runtime. Inputs: hour of day, day of week, mood tag, last-session gap. Output: risk score 0–1. Runs in under 5ms. Predicts your personal doom-scroll windows before they happen.

ONNX Runtime (on-device)
🧬

Behavioral Archetype Clustering

K-means clustering on session history identifies which behavioral type you are: "Night Scroller", "Stress Checker", "Morning Doom-scroller", "Boredom Tapper". Runs weekly via background task. Feeds the system prompt Claude receives.

ml5.js / custom k-means
Layer 2 — Claude API (Anthropic) — personalized narrative intelligence
✓ Primary choice

claude-haiku-3-5

Sub-1s responses, $0.25/M tokens. Exceptional at empathetic, non-preachy coaching tone. Follows nuanced system prompts precisely — critical for "never shame the user" requirement. Cheap enough for one call per session completion.

Use for: Insight cards, weekly reports, doom-loop messages, goal calibration

Selective use

claude-sonnet-4

Deeper reasoning for multi-turn coaching conversations. Worth the extra cost only when users are actively chatting with the AI coach — not for background generation tasks.

Use for: Interactive AI Focus Coach chat (premium feature)

Fallback only

GPT-4o mini

Comparable speed and cost to Haiku. Weaker at following tone nuance ("never shame, frame as curiosity"). Viable API fallback if Anthropic has downtime, but requires significantly more prompt engineering.

Gap: Claude's empathy framing is measurably better for wellness apps

Not recommended

On-device LLM (Llama 3B)

Models small enough for phones produce generic, low-quality coaching text that undermines trust. 400–800MB download. The quality gap vs Haiku is enormous — users will notice immediately.

Only use: Offline fallback for templated responses when zero connectivity

Smart Goal Calibration

During onboarding (and monthly), Claude analyzes the user's usage baseline and proposes a screen time goal with an explicit success probability. "Your current average is 4h 50m. A goal of 3h gives you a 71% chance of succeeding in week 1 based on similar patterns. Starting at 4h gives you 91%." Transforms goal-setting from aspirational to scientific.

What gets sent to Claude — structured context object

Claude receives a structured JSON context object, never raw session logs. Short, cheap prompts — and privacy-safe by design.

"user": { "name": "Arjun", "goal_minutes": 120, "archetype": "Night Scroller" },
"week_summary": {
  "avg_daily_screen_time": 187,       // minutes
  "goal_met_days": 3,
  "focus_sessions": 8,
  "doom_loops_detected": 4,
  "top_trigger_app": "Instagram",
  "top_trigger_time": "Sunday 21:00"
},
"mood_correlation": { "stressed": 0.7, "bored": 0.2 },
"vs_last_week": { "screen_time_delta": -12, "sessions_delta": +3 },
"request_type": "weekly_report"

No raw session logs. No timestamps. No personal content. Aggregated behavioral metrics only — GDPR-friendly by design.

Cost reality — keeping AI spend near zero

Claude is called only on meaningful events — never on a polling schedule. Free tier users get 5 insight cards as a hook, then AI coach is premium-only.

Feature Trigger Frequency Cost/User/Month
Session insight card Session completes ~20×/mo $0.004
Weekly coach report Sunday 8pm auto 4×/mo $0.006
Smart goal calibration Onboarding + monthly 1–2×/mo $0.001
AI coach chat (premium) User-initiated only ~10 msgs/mo $0.02
Total per active user / month ~$0.03

At 1,000 active users → ~$30/month total AI spend. Covered entirely by 3–4 premium subscribers at $5.99/mo. The AI is essentially free at scale.

Why this AI architecture wins
🧠 The on-device layer makes the app feel instantly intelligent — doom loop detection fires in milliseconds with no network hop. Users experience the intelligence immediately, without waiting for an API call.
💬 Claude's tone alignment is the decisive advantage over GPT-4o mini for a wellness app. You can write a system prompt that says "never shame, always frame as curiosity" — and Claude follows it consistently. Generic LLMs drift.
📊 Passing a behavioral archetype (Night Scroller, Stress Checker) into the system prompt allows Claude to personalize every response without requiring the user to ever "set up" their AI — it figures them out automatically from pattern data.
🔒 The structured JSON approach means no raw personal data ever leaves the device. Aggregated metrics only — which also keeps token counts low and costs near zero.
🚀 The AI coach chat (premium) is what converts free users. After 2 weeks of personalized weekly reports, users will pay to ask "why do I do this?" and get a real, personalized answer back. No other screen time app offers this.
